# Лабораторные работы по Laravel

Этот репозиторий содержит мои решения лабораторных работ по курсу веб-разработки.

## О проекте
Учебный проект для освоения основ Laravel: маршрутизация, контроллеры, работа с базой данных через Eloquent ORM и шаблонизатор Blade.

## Основной стек
- **PHP 8.x**
- **Laravel 10.x**
- **MySQL**
- **Bootstrap**

## Как запустить
1. Клонировать репозиторий: `git clone ...`
2. Установить зависимости: `composer install`
3. Настроить `.env` файл
4. Запустить миграции: `php artisan migrate`
5. Запустить сервер: `php artisan serve`
